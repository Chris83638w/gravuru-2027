# H1 – neues Shop-Hauptbild für das Acryl-Türschild

**Von Chris freigegeben und als Hauptbild des bestehenden Shopify-Entwurfs übernommen.** Die vorhandenen Design- und Startvorlagen bleiben nach Chris' Klarstellung unverändert. H1 betrifft ausschließlich das Produktbild im Shop. Die zusätzliche Auswahl A/B/C/D ist hinfällig.

![H1 – Bildvorschlag](H1-Acryl-Vanessa-Krueger.png)

Das bisherige Hauptbild zeigt ein leeres schwarzes Schild. H1 zeigt die vorhandene Gestaltung „Vanessa Krüger“ mit Haus (TAE-V2A-8x5-D23) auf schwarzem Acryl, weißem Hintergrund und weichem Schatten. Format 1254 × 1254 Pixel, PNG. Das eingebaute Bildwerkzeug hat den visuellen Shopentwurf aus dem bisherigen Hauptbild und der vorhandenen nativen D23-Vorschau erzeugt; er ist kein Fertigungsbeleg und wird nicht als pixelgleicher Originalexport ausgegeben. Die Originaldateien der Gestaltung wurden nicht verändert.

Ziel: „Türschild Acrylglas 3 mm – Form und Größe selbst wählen“, Shopify-Produkt `16190784602492`. Lesend geprüft: Status DRAFT, bisheriges Hauptbild Media `70017733919100`. Chris bestätigte ausdrücklich: „Ja, H1 als Hauptbild verwenden“. H1 wurde einmal hochgeladen, demselben Produkt zugeordnet und auf Position 0 gesetzt. Anschließend wurde das Produkt erneut abgerufen: H1 ist das Hauptbild, das frühere leere Bild bleibt an Position 1 erhalten, der Status bleibt DRAFT. Keine Veröffentlichung.
