# Konkreter Teilauftrag

- GitHub-Issue / Teilauftrag:
- Produkt oder Designserie:
- Gewünschter Umfang / Anzahl:
- Material, Stärke und Größen:
- Vorhandene Originalquellen / Excel / Referenzen:
- Bestehende Produkt-/Design-IDs, falls vorhanden:
- Bestätigte Entscheidungen und zugehörige Quellen:
- Tatsächlich offene Fragen:
- Ziel: Bildentwurf / Designpaket / Produktpaket / freigegebener DRAFT-Import:

## Lieferumfang

- [ ] Quellen- und Produktübersicht
- [ ] Eindeutig bezeichnete Bild-/Designentwürfe
- [ ] Vollständige Produkttexte, SEO, Preise und Optionen, soweit beauftragt
- [ ] Sichtbare PC-/Handyprüfung und passende fachliche Tests
- [ ] Zusammenhängendes Freigabepaket
- [ ] Quellen, Prüfsummen und Übergabe mit Commit/PR

## Entscheidungen

Hier nur tatsächliche Nutzerfreigaben mit Datum und Quelle eintragen. Leere Checkboxen sind keine Freigabe. Produktveröffentlichung und produktive Appänderungen bleiben eigene Schritte.
