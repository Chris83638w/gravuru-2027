# Galerie-Nachtrag 3: lokale Bedienprüfung

Gebauter Editor, lokaler Testtransport. Desktop 1440 × 900, Handy 390 × 664 und 375 × 548. Kein Live-Shop-Test und keine Produkt-/Preisfreigabe.

- [Desktop: Vorbereitung](desktop-vorbereitung.png)
- [375 × 548: Vorbereitung](375x548-vorbereitung.png)
- [390 × 664: Galeriefehler](390x664-fehler.png)
- [375 × 548: Galeriefehler](375x548-fehler.png)

In beiden Fällen wurde anschließend „Erneut versuchen“ geklickt: eine Testkarte erschien, der Dialog ließ sich schließen und der bestehende Editor blieb verfügbar. Die Kartenantwort und der Fehler waren für diese Bedienprüfung gezielt simuliert. Echte HTML-502-Antworten, Netzwerkfehler und der 5-Sekunden-Abbruch sind zusätzlich im Clienttest geprüft.

Die historische Datenkopie enthält zwei reale Produktvorlagen mit lokalen Testbindungen. Sie ersetzt nicht die noch ausstehende aktuelle Acryl-Store-Kopie mit den Funkklingelvarianten. Details in historische-kopie-messung.json.
