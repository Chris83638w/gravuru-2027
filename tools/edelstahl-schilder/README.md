```
ES_FAMILY=<gravuru-katalog>/familien/edelstahl/steel-door-signs.json ES_OUT=<ordner> python3 tools/edelstahl-schilder/edelstahl-html.py
```
Anzeige-Regeln: Ellipse unter „Oval“ (Chris 01.11.), je Form nach Seitenverhältnis-Reihen sortiert, blaue Haarlinie.
