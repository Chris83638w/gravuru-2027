- **Gestaltung:** Rand 0 mm erlaubt. Startdesign immer für „ohne Befestigung“. Wegen Bohrlöchern muss nichts verschoben werden, das macht künftig der Konfi bei der Befestigungswahl (Astra 1, #48 Nachricht 36). Name bzw. Hauptaussage klar als Hauptzeile, nichts leer oder gedrängt. Chris verkauft nur über die Optik.
